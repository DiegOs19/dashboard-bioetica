# Dashboard sobre Bioética

El problema ha enfrentar es el trabajo tardio y manual que la dependencia de gobierno enfrenta en cuestión de gestión y analisis de datos, 
en este caso se cuentan con considerables cantidades de datos en formatos tediosos de excel los cuales se recopilan de manera manual a lo largo
de cada año desde la creación de la dependencia, por lo que si el mero proceso de recolección de datos es tedioso pero necesario, avanzando al
siguiente paso del analisis y creación de contenido visual es un proceso el cual tengo el objetivo de optimizar mediante el desarrollo de un
dashboard directamente conectado a la base de datos de la dependencia, de esta manera aun despues de que termine el desarrollo de dicha herramienta, está pueda seguir manteniendose y actualizandose directamente segun la base de datos, de esta menra no haciendola dependiente
de mi persona, pero si en dado caso de que la pedencia requiera un mantenimiento o ajuste para el dasboard, mi responsabilidad y compromiso con el trabajo pedido me hara dar el seguimiento adecuado.

## Funciones

- Comparación anual entre hospitales
- Evolución histórica hospitalaria
- Evolución estatal
- Análisis por dominios
- Dashboard interactivo

## Tecnologías

- Python
- Streamlit
- Pandas
- Matplotlib
